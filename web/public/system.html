System blueprint · web3_proj

Every component of the MVP, on one page.

A vehicle marketplace where a buyer’s USDC is held by a smart contract until delivery is confirmed. Four layers, twenty-three endpoints, one escrow state machine, and a real EVM. This page is the complete map; the interactive version lives at the main site (sign in with the demo credentials).

CANCELLED         REFUNDED              DISPUTED ──arbiter──▶ REFUNDED | RELEASED

Transaction path

POST /api/escrows/:id/fund
  → EscrowService: state + role checks
  → viem walletClient.writeContract  (signed locally)
  → anvil mempool → block → execution → logs
  → waitForTransactionReceipt (status must be success)
  → escrow.status updated in PostgreSQL
  → indexer getLogs → decode → ChainEvent row
  → UI advances
