Deploy the escrow from your own wallet

Two ways to get this onto Sepolia. Either one ends with the operator repointing the API at the new addresses.

Fastest — one transaction

Send 0.01 Sepolia ETH to the deployment address. The operator then runs the deploy script, which creates both contracts and funds every signer. One signature instead of six.

Or do the whole deployment yourself

Six transactions, signed by you. Nothing leaves your wallet except gas.

  1. Deploy a 6-decimal test USDC token
  2. Deploy the escrow, naming the API’s arbiter key
  3. Mint 1,000,000 USDC to the demo buyer — the API signs as that account, not as you
  4. Send 0.003 ETH to the demo buyer for gas
  5. Send 0.003 ETH to the demo seller for gas
  6. Send 0.003 ETH to the arbiter for gas

All three signers need gas: buyer funds and confirms, seller ships, arbiter refunds. The USDC goes to the demo buyer for the same reason — the API signs as that account, not as you.
